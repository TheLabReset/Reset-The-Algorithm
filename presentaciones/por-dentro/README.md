# The Algorithm, por dentro

Presentación de inducción: de dónde viene cada dato, cómo lo recibimos, cómo se transforma y cómo se ve. La imagen que ordena todo es una **central de monitoreo** con dos pisos: abajo el cuarto de máquinas (el backend), arriba la sala (el frontend), y entre ellos un solo ducto (el contrato).

Cada tema se cuenta en tres tiempos, siempre en el mismo orden: **en la central** (la metáfora), **por dentro** (el código real dibujado como mecanismo, con el kit de Anatomy) y **en pantalla** (el panel real). La tecla **T** abre la capa técnica de cada lámina: el archivo, el código y la regla exacta.

- `node build.mjs` arma `por-dentro.html`: un solo archivo, sin nada externo, para presentar en pantalla completa (flechas o clicker; F para pantalla completa).
- `figuras/`: las figuras isométricas. Cada pieza corresponde a un paso real (por ejemplo, el cuarto de máquinas sigue el orden de `.github/workflows/pipeline.yml` del repo de producción).
- `kit/`: el kit de Anatomy (licencia MIT en `kit/LICENSE-anatomy`).
- `assets/`: tipografías, logo, GSAP y la captura de la maqueta con corte fijo al 25 de octubre de 2026.

La señal que sigue toda la presentación es un día de una pieza de Fit Lab (la marca ficticia de la maqueta): «Rutina guiada · anuncio de búsqueda», Google Ads, 25 de octubre, $20,59, 28 clics, 0 leads. Sale de `generar()` con la semilla 20260930 y corte al 25 de octubre, así que da siempre lo mismo.
